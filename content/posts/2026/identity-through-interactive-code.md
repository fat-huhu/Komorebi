# Building Personal Identity Through Interactive Code

同样是“个人主页”，有人做出来像模板，有人做出来像作品。差别通常不在设计资源，而在是否把个性真正编码进页面。

## Tone is interaction

交互不是中性的。按钮的停顿、文字的出现方式、滚动的惯性，都会传达性格。

## Repetition builds signature

品牌感来自重复。你在首页、博客页、文章页里反复使用相近的节奏、排版和光效，用户才会记住这是同一个人的系统。

## Code is not just implementation

代码不只是把图做出来，它也决定界面的气质边界。什么时候收，什么时候放，什么时候故意不解释，这些都在实现层发生。
